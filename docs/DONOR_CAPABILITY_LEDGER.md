# JARVIS Donor Capability Ledger

Source (historical): the owner's own JARVIS ZIP and snapshot (58 files), removed from the repository on 11 October 2026 (manifest in [ToRemove](../ToRemove.md)); retrievable only from Git history. Never reimport. Its LICENSE named the owner as copyright holder. This ledger records which active OCADE modules descend from it, for the P00-B rights review.

Classes: **KEEP** (logic reused as-is in the active runtime), **ADAPT** (logic copied/adapted into an OCADE executor), **REPLACE** (capability delivered by an OCADE authority instead), **PRESERVE UNUSED** (kept only in the immutable donor), **REMOVE FROM ACTIVE** (a verbatim copy exists under `jarvis-runtime/` but is not wired; delete once the adapted path is proven).

Active authority: `ocade_device.py` (exchange loop, STOP, one action at a time) -> `ocade_computer.py` (apps, files, commands, screen, system) and `actions/browser_control.py` (browser). Server: `src/jarvis/device.server.ts` (dispatch-time permission/confirmation/lease checks).

## Verbatim copies in `jarvis-runtime/` — removed 2026-10-01 (Phase 48)

The donor files copied into `jarvis-runtime/` but never wired into the agent (`actions/{code_helper,computer_control,computer_settings,desktop,dev_agent,file_controller,file_processor,flight_finder,game_updater,open_app,proactive,reminder,screen_processor,send_message,system_monitor,weather_report,web_search,youtube_video,background_monitor}.py`, `core/*`, `memory/*`, `dashboard/*`, `plugins/*`, and the donor's broad `requirements.txt` / `setup.py`) are removed. Every capability marked ADAPT above lives in an OCADE module the agent actually runs (`ocade_computer.py`, `ocade_settings.py`, `ocade_documents.py`, `ocade_sheets.py`, `ocade_wake.py`, `actions/browser_control.py`); the originals remain byte-for-byte in the immutable donor. Proof that nothing used them: the import graph from `ocade_agent.py`, `ocade_device.py` and every runtime test reached none of them, and the runtime tests, the packaged health check and the device journeys pass without them. This also removes the last provider-key reader (`core/gemini.py`) and the customer plugin loader from the active tree.
