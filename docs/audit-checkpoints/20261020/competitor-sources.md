# Primary-source competitor review — 20 October 2026

This is documentation research, not competitor execution or an OCADE benchmark. Sources were searched/opened on 20 October (Asia/Calcutta); publishers' capability descriptions are not independently verified success rates. No competitor software, donor source, runtime, extension, paid plan or recurring task was installed or activated. No superiority claim is supported. [BENCH-20-01](../../../BLOCKED_TESTS.md) remains BLOCKED.

| Product / project      | What the primary source establishes                                                                                                                                                                                                                                                                   | Implication to verify in OCADE; not a new framework                                                                                                                                                       |

| Grok Bot               | Its persistent cloud computer shares browser sessions, files and command credentials across an account's bots. Separate screens are not separate security boundaries. [Computer and apps](https://docs.x.ai/grok-bot/computer-and-apps)                                                               | Prove account/device/task isolation and one mutation owner for a shared app/document. A second chat must not inherit another task's authority.                                                            |

[Agent approvals and security](https://learn.chatgpt.com/docs/agent-approvals-security#sandbox-and-approvals)                          | Prove the selected device and permissions on each surface. This source is policy evidence; a full Dots feature/performance audit is still open.                                                           |

OCADE must not silently substitute a separate profile or require a customer extension.                             |

The published mobile benchmark is not OCADE's success denominator. No prohibited emulator was run. |

## Evidence still required for a comparison

Use the same disposable task inputs, human instructions, allowed accounts, time budget and independent checker for both products. Preserve editable outputs, trace identity, application versions, intervention and every failed/unknown/unsafe completion. Report attempted/verified/failed counts per workflow family, p50/p95 elapsed time, provider calls/tokens/Neurons and actual included-capacity usage. A changed candidate or different execution environment needs separate evidence.

No matched competitor/OCADE run has been completed in this continuation. Accuracy, speed, reliability and UX rankings are therefore unmeasured. Research suggestions above are engineering inferences, not independently observed competitor shortcomings or permission to import donor code, spend money, create accounts or run scheduled jobs.
