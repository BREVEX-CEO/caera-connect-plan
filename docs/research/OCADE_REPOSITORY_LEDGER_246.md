# OCADE repository ledger: the 246 repositories (14 November 2026)

**What this is.** One row per repository the owner listed: what OCADE takes from it, or why not, with the evidence. `plan.md` stays the authority; nothing here changes an owner decision.

**Evidence, stated plainly (this replaces the 13 November knowledge-only triage).**

- All 246 were attempted as shallow clones on 14 November 2026. **244 were cloned**; 2 need credentials (private, renamed or absent) and are marked UNREACHABLE.
- **D: cloned and scanned.** Every cloned repository's source tree was scanned by a script: licence file, HEAD, lines of code per language, manifests, SKILL.md count, GitHub links in its Markdown, and 28 capability probes (UI Automation, AX, AT-SPI, OCR, set-of-mark, tree diff, event hooks, background input, replay, MCP, A2A, sandboxing, checkpoints, verifiers, memory, compaction, handoffs, approvals, rate limits, OpenTelemetry, action caches, Office, browsers, network idle, prompt caching, skills), each with the files that match. The row's "scan" note gives the strongest probes and one file.
- **R: source reviewed.** The 58 repositories that touch desktop control, browser control, computer-use agents or the planner runtime were also read file by file. Their mechanisms, with file:line references, are in [`OCADE_SOURCE_REVIEW_2026-11-14.md`](OCADE_SOURCE_REVIEW_2026-11-14.md).
- A D row was not read line by line. Where it says REJECTED, the reason is a rule the code's own structure shows it breaks: a second framework or controller, local inference, provider pooling, paid infrastructure, a licence, or no code at all. A link list's links were counted, not followed: the repositories they point to are outside the 246.

**Licence rule used.** Nothing was copied. Every IMPLEMENTED row is an independent re-implementation of an idea in OCADE's own code, so no third-party licence obligation arises. AGPL/GPL, BSL and unlicensed code is never bundled (OCADE is proprietary); ideas from it are noted only. A future port or bundled binary must add its notice to `THIRD_PARTY_NOTICES.md` in the same commit.

**Dispositions.**

| Disposition     | Meaning                                                                                                                       |
| --------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| IMPLEMENTED     | A capability from it is now in OCADE's code, re-implemented, with the commit                                                  |
| PRESENT         | OCADE already uses it or an equal                                                                                             |
| PLANNED (gated) | Useful and compatible; not coded yet because a gate is unmet (a hosted desktop ladder, a live measurement or an owner choice) |
| EVAL-ONLY       | Useful for qualification or development; never shipped                                                                        |
| INDEX           | A link list or example collection; no capability to take                                                                      |
| REJECTED        | Not taken; the reason names the rule, the licence or the defect                                                               |
| DUPLICATE       | Same project as another row                                                                                                   |
| UNREACHABLE     | Could not be cloned without credentials                                                                                       |
