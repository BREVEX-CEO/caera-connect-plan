# OCADE repository ledger: the 246 repositories (13 November 2026)

**What this is.** One row per repository the owner listed, with what OCADE takes from it or why not. It extends the source-level research of 41 of them ([`docs/OCADE_INTEGRATION_RESEARCH.md`](../OCADE_INTEGRATION_RESEARCH.md) §3–§4). `plan.md` stays the authority; nothing here changes an owner decision.

**Evidence, stated plainly.**

- **[S]** source-inspected: the 41 repositories shallow-cloned and read on 12 November 2026 (research §4, paths and licences there).
- **[K]** knowledge-only: the other 205 were **not** cloned or read in this session (this session's GitHub access covers OCADE's own repository only). Their rows rest on what the repository is known to be. A [K] row is a triage decision, not a code audit; where it says PLANNED, the source must be read before anything is ported.
- Licences are given only where research §4 verified them, or marked [knowledge].

**Licence rule used.** Nothing was copied. Every IMPLEMENTED row is an independent re-implementation of an idea or pattern in OCADE's own code, so no third-party licence obligation arises from it. A future port or bundled binary (PLANNED rows) must add its notice to `THIRD_PARTY_NOTICES.md` in the same commit; AGPL/GPL code is never bundled (OCADE is proprietary, research §2), but its ideas may be re-implemented.

**Dispositions.**

| Disposition     | Meaning                                                                                                                                 |
| --------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| IMPLEMENTED     | Its capability is now in OCADE's code, re-implemented, with the commit                                                                  |
| PRESENT         | OCADE already uses it or an equal                                                                                                       |
| PLANNED (gated) | Useful and compatible; not coded yet because a gate is unmet (a desktop ladder, a live measurement, a signing step, or the source read) |
| EVAL-ONLY       | Useful for qualification or development; never shipped                                                                                  |
| INDEX           | A link list; no code to take                                                                                                            |
| REJECTED        | Not taken; the reason names the rule or the duplicate                                                                                   |
| DUPLICATE       | Same project as another row                                                                                                             |
