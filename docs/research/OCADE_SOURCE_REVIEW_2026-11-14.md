# Source review of the desktop, browser, CUA and runtime repositories (14 November 2026)

Read-only review of the actual source files (not READMEs) of the 58 repositories of the 246 (plus bytedance/UI-TARS, in place of the unreachable alibaba/UI-TARS) most relevant to OCADE's
desktop and browser control, shallow-cloned at the HEAD shown. Every other repository of the 246 was cloned
and scanned by `digest` (licence, languages, lines of code, manifests, capability probes with file paths);
see the ledger. Paths are relative to each repository. "TAKE" means the idea is re-implemented in OCADE's
own code (nothing is copied); "ALREADY" means OCADE has it or better; "REJECT" gives the technical reason.
