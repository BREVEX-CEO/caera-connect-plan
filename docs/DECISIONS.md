## Decisions superseding older instructions

- One website-first OCADE: Chat retains Auto/Online/Offline; JARVIS remains separate and online-only. Native work uses the existing paired signed companion; no mandatory extension, store or customer MCP setup.
- One planner/broker/identity/permission/task/installation authority. Deterministic bounded local execution plus independent receipts replaces model-owned success and unnecessary cloud turns.
- Existing browser sessions are used only through legitimate supported access. No cookie copying, insecure debug port or promise that a webpage controls every installed app. Apple platform limits remain explicit.
- Preserve native fidelity, useful Office adapters, originals, STOP, recovery and immutable provenance. Reuse techniques where safe and licensed; the older approximately98% reuse aspiration is not a requirement to copy restricted or unsafe code.
- Bundled signed wake assets supersede old post-install download wording. One audio owner; local pre-wake privacy; speech interruption and task cancellation are different operations.
- The integrated owner/staff console supersedes the retired separate admin origin. Current paid checkout is retired; grants/entitlements remain. Future payments require approved merchant/legal and settlement proof.
- Workers/R2 is the current deployment platform. No Pages migration is proposed. Applied migrations remain immutable and replay chronologically; deployment procedures live only in Testing.
- P00–P22 replace old phases1–56/addenda. Evidence per capability replaces ungrounded overall readiness percentages. Historical TOTP and other defect statements must be reproduced before being called current.
- Current documentation publication is explicitly authorised. The earlier blanket stop-before-main rule does not prohibit it; production changes still require their separate owner approval.
