## Finished files, honest provenance and the Elite Work Standard — 22 October 2026

**Decision (engineering, owner roadmap `phases.md` items 9, 24, 44, 74, 108):** a completed task hands over the files its checks name and it made: the device uploads each to the person's own folder of the private Library bucket through an upload address only OCADE's server mints, and the server records Library items only from delivered actions of a verified completion. The task card offers Open and Download through short-lived signed links. When the person named a site and a command on the computer made a finished file instead, the result says so per file, whatever the model wrote (the device reports which files each command changed); the model's own disclosure was ignored in four real runs. A checked file that exists but is empty (no bytes, a model with no triangles) is never a completed result.

**Decision (Elite Work Standard, PROMPT-22-01):** implemented word for word behind `ocade.prompt` = `elite`; on matched real runs it did not beat the current instructions (photo 0/2 versus 2/2, CAD 0/2 versus 0/2), so it stays off.
